# คู่มือติดตั้งระบบใบรายงานการทำงานของเครื่องจักรกลช่วย

ระบบนี้ประกอบด้วย 3 ส่วน ทำงานร่วมกันแบบ **ไม่ต้องมีเซิร์ฟเวอร์ / ฟรี**

```
พนักงานขับรถ  ──ส่งข้อมูล──▶  Google Sheet (ฐานข้อมูล)  ──โหลด──▶  เสมียน (พิมพ์)
   index.html                    ผ่าน Apps Script                    index.html
```

ไฟล์ในโฟลเดอร์:
- **index.html** — หน้าเว็บกรอก/พิมพ์ (เปิดด้วยเบราว์เซอร์)
- **logo.png** — โลโก้หัวเอกสาร (ต้องอยู่คู่กับ index.html เสมอ)
- **google-apps-script.gs** — โค้ดฝั่ง Google (นำไปวางตามขั้นตอนด้านล่าง)

---

## ขั้นตอนติดตั้ง (ทำครั้งเดียว ~5 นาที)

### 1) สร้าง Google Sheet
1. เข้า https://sheets.google.com สร้างสเปรดชีตใหม่ 1 ไฟล์ ตั้งชื่อเช่น “รายงานเครื่องจักรกลช่วย J2411”

### 2) วางโค้ด Apps Script
1. ในสเปรดชีต เมนู **ส่วนขยาย (Extensions) → Apps Script**
2. ลบโค้ดเดิมในช่องออกให้หมด แล้ว **คัดลอกเนื้อหาทั้งหมดจากไฟล์ `google-apps-script.gs`** มาวาง
3. กด **บันทึก** (ไอคอนแผ่นดิสก์)

### 3) เผยแพร่เป็น Web App
1. มุมขวาบน กด **ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้ใหม่ (New deployment)**
2. ไอคอนเฟือง ⚙ เลือกประเภท **แอปเว็บ (Web app)**
3. ตั้งค่า:
   - **ดำเนินการในนามของ (Execute as):** ฉัน (Me)
   - **ผู้ที่มีสิทธิ์เข้าถึง (Who has access):** **ทุกคน (Anyone)**  ← สำคัญ
4. กด **ทำให้ใช้งานได้** → อนุญาตสิทธิ์ (Authorize) ตามที่ระบบถาม (เลือกบัญชี → ขั้นสูง → ไปที่โปรเจกต์ → อนุญาต)
5. คัดลอก **URL แอปเว็บ** ที่ได้ (ลงท้ายด้วย `/exec`)

### 4) ใส่ URL ลงในหน้าเว็บ
1. เปิดไฟล์ **index.html** ด้วย Notepad หรือ VS Code
2. หาบรรทัด (อยู่ต้น ๆ ของ `<script>`):
   ```js
   const GAS_URL = "";
   ```
3. วาง URL ที่คัดลอกมาไว้ในเครื่องหมายคำพูด:
   ```js
   const GAS_URL = "https://script.google.com/macros/s/AKfyc...../exec";
   ```
4. บันทึกไฟล์

เสร็จแล้ว! 🎉

## วิธีใช้งานประจำวัน

### พนักงานขับรถ
1. เปิด **index.html** (โหมด “👷 พนักงานขับรถ”)
2. กรอกข้อมูล (กรอกได้หลายรอบระหว่างวัน) และ **เซ็นชื่อบนหน้าจอ** ได้เลย
3. กด **“💾 บันทึกร่าง”** เพื่อเก็บขึ้น Google Sheet ไว้ก่อน (สถานะ = **ร่าง**)
   - บันทึกซ้ำที่ **แถวเดิม** ทุกครั้ง (ไม่สร้างข้อมูลซ้ำ)
   - ระหว่างกรอกระบบยัง **สำรองในเครื่องอัตโนมัติ** กันข้อมูลหาย/เน็ตหลุด
4. **เปิดต่อจากอีกเครื่องได้:** ที่เครื่องใหม่กด **“📥 โหลดร่าง”** → เลือกใบที่ค้างไว้ → แก้ไขต่อ
5. กด **“👁️ ดูตัวอย่าง”** ตรวจความถูกต้อง
6. พอเลิกงานกด **“📤 ส่งเข้าระบบ”** ครั้งเดียว → เปลี่ยนสถานะเป็น **ส่งแล้ว** (เสมียนจึงจะเห็นและพิมพ์ได้)

### เสมียน
1. เปิด **index.html** แล้วกดปุ่ม **“🖨️ เสมียน (พิมพ์)”**
   *(หรือเปิดลิงก์ `index.html?role=clerk` ให้เข้าโหมดเสมียนเลย)*
2. กด **“🔄 โหลดรายการ”** → เลือกใบที่ต้องการจากรายการ
3. กด **“🖨️ พิมพ์”** → ตั้งกระดาษ **A4 แนวตั้ง** แล้วสั่งพิมพ์ หรือบันทึกเป็น PDF

## การนำไปใช้จริง (แนะนำ)
- **วางไฟล์บนที่แชร์กัน** เช่น Google Drive / OneDrive / โฟลเดอร์เครือข่าย ให้ทั้งพนักงานและเสมียนเปิดไฟล์ชุดเดียวกัน
- หรืออัปโหลดขึ้น **โฮสต์ฟรี** (GitHub Pages / Netlify) เพื่อให้เปิดผ่านมือถือได้ด้วย URL เดียว
- ข้อมูลทั้งหมดอยู่ใน Google Sheet — เปิดดู กรอง หรือทำรายงานสรุปเพิ่มเติมได้ตามต้องการ

## สถานะข้อมูลใน Google Sheet
- คอลัมน์ **สถานะ** จะเป็น **“ร่าง”** (ยังกรอกไม่เสร็จ) หรือ **“ส่งแล้ว”** (พนักงานยืนยันส่ง)
- โหมดเสมียน (พิมพ์) จะเห็น **เฉพาะที่ “ส่งแล้ว”** เท่านั้น
- แต่ละใบมีคอลัมน์ **id** เพื่ออ้างอิงแถวเดิม — บันทึกร่างกี่ครั้งก็อัปเดตแถวเดียว ไม่ซ้ำ

> **สำคัญ:** ถ้าเคยติดตั้งเวอร์ชันก่อนหน้า (ยังไม่มีคอลัมน์ id/สถานะ) ให้ **ลบแท็บ “Reports” เดิมทิ้ง** แล้ว Deploy โค้ดใหม่ ระบบจะสร้างหัวตารางชุดใหม่ให้เอง

## แก้ปัญหาเบื้องต้น
- **กดส่งแล้วขึ้น “ยังไม่ได้ตั้งค่า GAS_URL”** → ยังไม่ได้ใส่ URL ในขั้นตอนที่ 4
- **ส่ง/โหลดไม่สำเร็จ** → ตรวจว่าตอน Deploy เลือก “ผู้ที่มีสิทธิ์เข้าถึง = ทุกคน (Anyone)”
- **แก้โค้ด .gs แล้วไม่อัปเดต** → ต้อง Deploy ใหม่ (Manage deployments → แก้ไข → เวอร์ชันใหม่)
- **โลโก้ไม่ขึ้น** → ต้องมีไฟล์ `logo.png` อยู่โฟลเดอร์เดียวกับ index.html
